# Questions et réponses de soutenance

1. **À quoi sert Angular CLI ?** Il initialise le projet, compile l’application et lance le serveur de développement. [Code](../angular.json)
2. **Que signifie standalone ?** Le composant déclare directement les dépendances de son template. [Code](../src/app/app.component.ts)
3. **Pourquoi le mode strict ?** Il détecte notamment les types incompatibles et les valeurs potentiellement absentes. [Code](../tsconfig.json)
4. **Pourquoi des interfaces ?** Elles décrivent les champs attendus pour chaque entité. [Code](../src/app/models/study.ts)
5. **Pourquoi une union de littéraux ?** Elle fixe les valeurs possibles des statuts, rôles et priorités. [Code](../src/app/models/study.ts)
6. **Pourquoi une propriété facultative ?** Une tâche peut exister sans description ou date de réalisation. [Code](../src/app/models/study.ts)
7. **Comment communiquer entre parent et enfant ?** Le parent transmet la tâche par input et reçoit les actions par output. [Code](../src/app/components/task-card/task-card.ts)
8. **À quoi sert model ?** Il synchronise le texte du filtre avec le parent par liaison bidirectionnelle. [Code](../src/app/components/filter-bar/filter-bar.ts)
9. **Quels bindings sont utilisés ?** Interpolation pour un texte, propriété pour une valeur, événement pour une action et liaison bidirectionnelle pour la recherche. [Code](../src/app/pages/tasks/tasks-page.ts)
10. **Pourquoi utiliser track ?** Angular conserve l’identité des éléments de la liste grâce à leur identifiant. [Code](../src/app/pages/tasks/tasks-page.ts)
11. **À quoi sert ngOnInit ?** Il déclenche le premier chargement de la page. [Code](../src/app/pages/dashboard/dashboard-page.ts)
12. **Quels pipes natifs apparaissent ?** Date formate l’échéance, UpperCase transforme un libellé et Percent formate le taux. [Code](../src/app/pages/dashboard/dashboard-page.ts)
13. **Comment fonctionne DeadlinePipe ?** Il compare deux dates civiles pour afficher un délai ou un retard. [Code](../src/app/pipes/deadline.ts)
14. **Pourquoi un signal pour les tâches ?** Une mutation réussie change la collection observée par les pages. [Code](../src/app/services/api.ts)
15. **Pourquoi computed pour la progression ?** Le taux dérive du nombre de tâches terminées et du total. [Code](../src/app/services/api.ts)
16. **Pourquoi effect pour le titre ?** Le titre de l’onglet est une écriture dans le navigateur. [Code](../src/app/pages/dashboard/dashboard-page.ts)
17. **Comment le jardin évolue-t-il ?** Il passe cinq seuils à partir du taux fourni par le tableau de bord. [Code](../src/app/components/bloom-garden/bloom-garden.ts)
18. **Pourquoi inject ?** Angular fournit l’instance du service dans le contexte d’injection. [Code](../src/app/services/study.ts)
19. **Comment sont liées les tâches et matières ?** Le champ subjectId identifie la matière d’une tâche. [Code](../src/app/models/study.ts)
20. **Que fait le chargement différé ?** Le routeur importe la page lorsque sa route est demandée. [Code](../src/app/app.routes.ts)
21. **Comment récupérer l’identifiant d’une tâche ?** Le composant lit le paramètre id de la route activée. [Code](../src/app/pages/tasks/task-editor.ts)
22. **Pourquoi debounceTime ?** Il attend 300 ms après la dernière émission avant de chercher. [Code](../src/app/pages/tasks/tasks-page.ts)
23. **Pourquoi switchMap ?** Il se désabonne de la recherche précédente lorsqu’une nouvelle commence. [Code](../src/app/pages/tasks/tasks-page.ts)
24. **Comment la recherche est-elle envoyée à l’API ?** Le service transmet title_like et les identifiants des matières. [Code](../src/app/services/api.ts)
25. **Comment traiter une erreur HTTP ?** catchError affiche une erreur dans l’état de la page ou du formulaire. [Code](../src/app/pages/page-state.ts)
26. **Comment éviter une fuite d’abonnement ?** takeUntilDestroyed termine les abonnements à la destruction de la page. [Code](../src/app/pages/page-state.ts)
27. **Comment l’échéance est-elle validée ?** Une nouvelle date passée est refusée. Une ancienne date conservée permet de modifier le statut. [Code](../src/app/validators/deadline.ts)
28. **Comment le jeton est-il transmis ?** L’interceptor clone la requête vers l’API et ajoute Authorization Bearer. [Code](../src/app/interceptors/token.ts)
29. **Comment sont contrôlés les rôles ?** Les guards décident de la navigation selon la session. JSON Server reste une API locale de démonstration. [Code](../src/app/guards/session.ts)
30. **Comment protéger les catégories utilisées ?** La page consulte les matières avant de supprimer la catégorie. [Code](../src/app/pages/admin/admin-page.ts)
