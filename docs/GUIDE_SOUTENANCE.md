# Guide de soutenance

1. Démarrer l’API et Angular dans deux terminaux. Présenter le modèle relationnel et ouvrir l’espace de Lina.
2. Montrer le tableau de bord et les calculs du jardin. Passer dans les tâches, rechercher « Angular » et activer la vue Kanban.
3. Créer une tâche liée à une matière. Montrer le validateur d’échéance, la page paramétrée et la modification du statut.
4. Recharger la page pour montrer la persistance, puis consulter les échéances dans le calendrier.
5. Se connecter comme administrateur. Rechercher un utilisateur et essayer de supprimer une catégorie utilisée.
6. Ouvrir les fichiers des guards, de l’interceptor, de la recherche RxJS et du jardin. Expliquer la portée pédagogique du JWT.

La date de soutenance indiquée dans le cahier des charges est le 23 janvier 2027.
